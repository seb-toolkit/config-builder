Downloads for staff: Safe Exam Browser, SEB Server and tools

Published 2026-11-26 · Unofficial guide

This page lists where staff get Safe Exam Browser (SEB) and related tools. The SEB programs come from the official project; this site links to them and does not host them.

Safe Exam Browser

PlatformSourceListed version (26 Nov 2026)
Windows 10 (1803 or later) and 11Official download page (installer from GitHub or Codeberg)3.10.3
macOSOfficial download page (disk image on GitHub)3.7.2
iOS / iPadOSApp Store3.7.2

The official page also has former releases, checksums for Windows and Mac, and an integrity checker, the SEB Verificator. Versions change often, so check the page before each term. Apple’s signing certificate updates have affected older Mac versions on newer macOS releases, so update Macs before an exam period.

For servers and learning systems

  • Moodle: the Safe Exam Browser quiz access rule has been built into Moodle since version 3.9. The official page also lists a plugin on GitHub for older versions.
  • ILIAS: a plugin is listed on the official page.
  • SEB Server: no download on the official page. It links to the SEB Server project on GitHub. You run your own instance or use a provider. See logging, hosting and firewalls.
  • Autologin plugin for Moodle: moodle-quizaccess_seb_autologin. Check how it fits your sign-in method.

Tools on this site

  • SEB Config Builder: makes the .seb settings file, tests which websites the exam uses, and makes printable information sheets for students, invigilators and IT.
  • Student guides you can link from quiz instructions.

Rolling it out

  1. Choose a supported version and say which one in your student instructions.
  2. Lab computers: install the same version on every computer or add it to the image, then test the file on one.
  3. Students’ own computers: link to the student download page and ask them to install by a date.
  4. Test before the exam: see how to do a test run.
  5. Keep records: the versions you tested and the exact settings file.

Version details were read from the official page on 26 November 2026. Confirm them before you rely on them.
