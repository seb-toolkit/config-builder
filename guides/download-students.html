Download Safe Exam Browser: student downloads and installation

Published 2026-11-26 · Unofficial guide for students

You only need to install Safe Exam Browser (SEB) once, and update it when your exam asks for a newer version. Download it from the official project or the link your university gives you. This site does not host SEB: that way you always get the real, current build from its makers.

Your university’s instructions come first. If they name a version or give you a different link, use theirs.

Official downloads

ComputerWhere to get itNotes
Windows 10 or 11safeexambrowser.org/download_en.htmlDownload the installer from the official page, then run it. As of 26 November 2026 the page lists version 3.10.3.
Macsafeexambrowser.org/download_en.htmlA disk image. As of 26 November 2026 the page lists version 3.7.2. Newer macOS versions need a recent SEB, so update before the exam.
iPad and iPhoneThe App StoreCheck with your university that iPad is allowed for your exam. Some features differ.

Version numbers change, so check the official page for the current ones. I could not find an official Linux or Chromebook version on that page. If you use one of those, ask your university about a university computer or another route.

Installing

  1. Windows: run the installer, accept the prompts and restart if asked.
  2. Mac: open the disk image and drag SEB into the main Applications folder. Leaving it in Downloads or a user folder can stop it starting.
  3. iPad: install it from the App Store.
  4. Do not start the exam from inside SEB yet. Start it from your exam page, using the launch button or link your university gives you.

Check you got the real one

  • Download only from safeexambrowser.org, the App Store or your university. Do not use other download sites or “bundles”.
  • The official page lists a checksum for the Windows and Mac downloads. You can compare it with your file if you know how, but it is not needed for most people.
  • Be wary of anything that says it can “unlock” or “bypass” SEB. See the risks of cheating.

After installing

  • Do the practice quiz, if there is one.
  • Run through the student checklist.
  • If something fails, see what to do if SEB won’t start.
