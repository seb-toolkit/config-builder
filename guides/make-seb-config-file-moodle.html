How to make a Safe Exam Browser (.seb) file for a Moodle quiz

Published 2026-11-26 · Unofficial guide

A .seb file is a small settings file for Safe Exam Browser (SEB). It tells SEB which page to open, how students leave, which websites are allowed and what they can do while the exam runs. This guide takes you from nothing to a file uploaded to a Moodle quiz.

Before you start

  • The quiz address. Open the quiz in your normal browser and copy the address from the bar.
  • A quit password. Students need it to leave SEB. Invigilators give it out at the end, or you skip it for practice quizzes.
  • Two test computers. One Windows and one Mac if students use both. You will try the file on them before the real exam.

Step 1: Pick the situation closest to yours

Open the SEB Config Builder. It starts with a handful of situations, such as a closed-book Moodle quiz, a practice quiz or an open-book exam. Each one lists in plain words what it assumes (full screen, only the quiz site allowed, copy and paste inside the exam only, and so on). Choose the nearest one and you can change every choice in the questions that follow.

Step 2: Answer the questions

  1. Exam address. Paste the quiz address.
  2. Computers. Tick Windows, Mac and iPad as needed. This only decides which settings are shown to you.
  3. Leaving SEB. Set a quit password, or let students quit freely. You can also give a quit link: a web address that makes SEB quit the moment it is about to open it. Pick one students would never click by accident (not the quiz, review or home page), such as https://moodle.example.ac.uk/seb-exit. Moodle shows an Exit Safe Exam Browser button for it on the quiz page once a student has finished an attempt.
  4. Websites. Only the exam site, the exam site plus others you list, or any website. See which sites to allow for Moodle.
  5. Microsoft sign-in. If students log in with a university Microsoft account, see the guide on Microsoft sign-in.
  6. Screen and features. Full screen or window; copy and paste; spell check, printing, back and forward; downloads and uploads.
  7. Moodle check. Whether SEB sends its keys. When you upload the file, Moodle switches this on itself, so the answer matters little for Moodle.

Step 3: Download the file

Check the summary, then download the .seb file. Everything runs in your browser, so nothing is uploaded anywhere. If you plan to reuse the choices, save them as a named setup first.

Step 4: Upload it to Moodle

In the quiz settings, open the Safe Exam Browser section and set Require the use of Safe Exam Browser to Yes – Upload my own config. Upload the file and save. Students then see a button to launch the quiz in SEB. They do not need the file on their own computers.

If you change the settings later, upload the new file to Moodle again.

What Moodle does with your file. This is from reading Moodle 4.5's Safe Exam Browser code and testing a builder file on it:

  • Moodle reads the settings itself, so the file must be a plain, unencrypted .seb file. The builder saves plain files by default. A file with a password, or one compressed by another tool, is rejected with a parse error when you upload it. (The builder only makes a password-protected file if you set a file password, so leave that blank for Moodle.)
  • Moodle replaces the start address with the quiz's own address, and turns on sending the browser exam key. The start address in your file does not decide where students land; it only helps the builder work out the website filter.
  • Students start the quiz from Moodle's launch button, which gives them Moodle's own copy of the settings.

Step 5: Test it

Install SEB on your test computers and start the quiz from Moodle. Check that:

  • the quiz opens full screen and the login works;
  • pages and images load (if something is missing, a website you need is probably blocked);
  • copy and paste behaves as you expect;
  • the quit password works and the quit link, if you set one, ends the session.

The builder follows SEB's published source code, but it is an unofficial tool. Always test a file in real SEB before an exam.

If the file will not open or upload

  • The name must end in exactly .seb. Some browsers add another ending such as .txt; rename the file if so.
  • Try copying the file to the Desktop and picking it from there.
  • If Moodle says the file cannot be parsed, it is probably compressed or password-protected. Make a new file with no file password.
  • If SEB rejects it, note the exact message and the SEB version. The settings and version matter.
