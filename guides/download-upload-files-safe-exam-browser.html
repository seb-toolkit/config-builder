Downloading and uploading files in Safe Exam Browser: where files go

Published 2026-11-26 · Unofficial guide

Some quizzes ask students to download a file (a dataset, a template) and then upload their work to Moodle. Safe Exam Browser (SEB) can allow this, but the details of where files go are not obvious. This guide is based on reading the SEB for Windows source code and its settings; the Mac side is covered more lightly.

Students do not need File Explorer

When a student clicks an upload button, SEB shows its own file dialog. The dialog is part of SEB, so File Explorer is not needed.

Where downloads are saved (Windows)

  • Files go straight to the download folder with no prompt. This is the folder in the setting downloadDirectoryWin. If it is empty, it is the user's normal Downloads folder.
  • If a file with that name already exists, SEB adds a number to the new file.
  • Only if "allow custom download and upload location" is on do students get a save dialog and a choice of folder.

What students can pick when uploading (Windows)

  • The dialog opens in the same download folder.
  • With the custom location setting off, which is the default, navigation is restricted: students can only choose from that folder.
  • With it on, students can browse the whole computer, including their own documents. That is rarely wanted in an exam.

The tidy-up problem

The restricted dialog still shows everything in the Downloads folder: old files, and on a shared lab computer, other people's. The fix is the setting use a temporary directory for downloads and uploads. SEB creates a fresh empty folder for the session and removes it when SEB quits, so the dialog shows only what the student just downloaded. According to SEB's own help text, the temporary folder is removed when the session ends.

On a Mac

SEB for Mac needs a master switch, allowDownUploads, in addition to the separate allow-downloads and allow-uploads settings. If it is off, downloads and uploads are blocked even when the other two are on. The Mac client also has a setting to reuse the most recently downloaded file when a student uploads, instead of showing a file picker. This guide has not checked how the Mac file picker is restricted, so test it.

Other things to remember

  • Allow the download site. If you filter websites and the file comes from a different host than Moodle, allow that host. See the URL filter guide.
  • Do not open downloads in other programs. On a Mac, "open files after downloading" would launch another application, which can let students out of the locked-down browser. Leave it off.
  • PDF files. By default SEB shows PDFs itself. A separate setting makes it download them instead, so check how your quiz links to PDFs.
  • iPad. SEB's own help warns that uploading on iOS gives access to the camera and full photo library.

Set it up in the builder

The SEB Config Builder has a template called "Download a file, then upload an answer". It turns on downloads and uploads, uses the temporary folder, keeps the custom location off, sets the Mac master switch, and asks you for the download site so it can be allowed. As always, test the file in real SEB first.
