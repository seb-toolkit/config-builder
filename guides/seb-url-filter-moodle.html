Safe Exam Browser URL filter for Moodle: what to allow and how to test it

Published 2026-11-26 · Unofficial guide

Safe Exam Browser (SEB) can limit which websites students open during an exam. This is the URL filter. Used well, it keeps students on the quiz. Used badly, it breaks images, equations or login. This guide explains how it behaves and how to build the right list.

How the filter decides

  • Block rules win. SEB checks Block rules first, then Allow rules. A web address that matches nothing is blocked.
  • The start page is allowed automatically. If your start address would otherwise be blocked, SEB adds an allow rule for it.
  • Matching ignores case, and addresses are decoded before they are matched.

Pages only, or everything on the page?

There are two levels:

  • Filter pages (the usual setting). Only the page a student navigates to is checked. Scripts, images and fonts that the page loads from elsewhere are not checked.
  • Filter embedded content as well. Every request is checked: images, scripts, frames and background requests. This is stricter, and every host the quiz uses must be allowed.

With page filtering, the list is short, often just your Moodle address and the sign-in site. Only switch on content filtering if you need it.

Writing patterns

PatternMatches
moodle.example.ac.ukThat site and its subdomains
.moodle.example.ac.ukThat host only, no subdomains (leading dot)
*.example.orgAny subdomain of example.org
example.org/path/*Anything under that path

You can also use regular expressions. Be aware that SEB for Windows uses the .NET regular-expression engine, which differs from some others in details, and SEB for Mac has its own implementation of the check that is close to the Windows one but not identical.

What a Moodle quiz usually needs

Moodle serves most of its own scripts, styles and files from the same address, so the Moodle host is usually enough. Things that commonly need extra entries:

  • Sign-in. Your university single sign-on, for example Microsoft (see the Microsoft guide), Shibboleth or SAML.
  • Equations. The MathJax filter loads from a content network by default in recent Moodle versions. Check the setting under Site administration, Plugins, Filters, MathJax. This only matters if you filter embedded content.
  • Embedded media. For example YouTube or Vimeo.
  • Site add-ons. Video platforms and similar tools your institution has installed.
  • A download site. If a question asks students to download a file from elsewhere, allow that site too.

Find the exact list instead of guessing

Record a real session and let the tool list every site:

  1. Open the quiz in Chrome, Edge or Firefox and press F12. Open the Network tab and tick Preserve log.
  2. Go through the whole quiz, including login and any embedded content.
  3. Export the recording as a HAR file, or right-click the list and copy all the URLs.
  4. Drop the file into Test the URL filter in the builder. It checks each address against your rules and offers an Allow site button for blocked hosts.

The tool reads only the address, request type, time and status of each request. It ignores cookies and headers, and nothing is uploaded. A HAR file can contain login cookies, so do not share one.

The matching code is a port of the filter in SEB for Windows and passes that project's own unit-test cases. Even so, test the finished file in real SEB.
